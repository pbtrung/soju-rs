# Commit and push

Follow the [repository commit skill](../../.agents/skills/commit/SKILL.md).
It is the maintained procedure for reviewing/staging scope, required checks,
commit messages, hooks, pushing and final status reporting. This command does
not maintain a separate set of rules.

An invocation requests commit and push unless the user specifies local-only.
[Repository guidance](../../AGENTS.md) applies. Editing this document or the
skill does not request either action.
